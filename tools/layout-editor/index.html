1. Load the correct data before editing

Mode + Layout first

Pick the right mode

  • Application Order: reorder apps and folders.
  • Default Workspace: edit real positions on each home screen.
  • Switch mode before importing data so the editor detects the file correctly.

Choose the layout profile

  • Use the preset that matches the device grid.
  • If you choose Custom grid, set Columns and Home rows, then click Apply Grid.
  • Grid Lines helps you see placement boundaries while editing.

Bring XML into the editor

  • Load XML: import from a file on your machine.
  • Paste XML: paste raw XML directly into the modal.
  • Use Add Item after loading if you want to insert new apps, folders, or widgets.

Canvas workflow

2. Edit visually on the middle canvas

Drag, double-click, right-click

Main interactions

  • Drag items to a new slot on the current page.
  • Use Previous and Next to move between pages.
  • Double-click a folder to open its contents.
  • Double-click an app or widget to open the edit dialog directly.
  • Right-click an item or empty slot to access Add Here, Edit Item, Move to Page..., Send to Cart, or Remove Item.

Tools

3. Use folders, cart, and compare tools to work faster

Power features

Folder modal

  • Open a folder with double-click.
  • Inside the folder modal, drag items to reorder them.
  • Use the folder-level Save and Reset buttons for folder changes.

Cart tray

  • Use Send to Cart to park an app or widget temporarily.
  • You can also drag supported items into the cart area.
  • Drag a cart card back to the canvas later to restore it.

Compare XML

  • Current Output vs Paste: compare the current editor result with pasted XML.
  • Two Custom Sources: compare any two XML texts side by side.
  • Use this before export when you need a fast diff review.

XML and output

4. Know which save button does what

Most important distinction

Left-side layout actions

  • Save: commits the current visual layout changes.
  • Reset: restores the layout to the last committed state.
  • Export XML: downloads the current output as an XML file.

Right-side XML editor actions

  • Show XML: opens or hides the XML panel.
  • Save XML: applies manual XML text edits back into the UI.
  • Reset XML: refreshes the editor text from the current layout.
  • Copy XML: copies the current XML text.
Good workflow: load XML, edit on canvas, optionally review in Show XML, run Compare XML if needed, then use Export XML.
Shortcut: inside the XML editor, press Ctrl + S to save XML text changes quickly.
