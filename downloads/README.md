# downloads/

Optional folder for hosting release builds straight from GitHub Pages.

1. Drop a zip here, e.g. `STM_v6.8.26-win-x64.zip`
2. Commit and push
3. In the admin console, set that tool's Download URL to `downloads/STM_v6.8.26-win-x64.zip`

Keep individual files under GitHub's 100 MB hard limit (50 MB triggers a warning). For bigger builds, use GitHub Releases and link the release asset URL instead.

Think before committing: files here are as public as the repository is.
